# Задания ученика — 13 сентября 2026

Сначала подготовлен растровый макет встроенным imagegen, затем экран собран в Next.js.
`concept.png` — концепция; `implemented-desktop.png` и `implemented-mobile.png` — реальные снимки локальной production-сборки на тестовых данных.

## Ответственность экрана

- Задания: список работ, их состояние, источник и переход к конкретному заданию.
- Внутри задания: материалы, отправка ответа, полная проверка и результат.
- Здесь нет календаря, баланса, учебного плана, статистики освоения тем.
- Старые отчёты обозначены «Из прошлых уроков». Частичная оценка не представляется новым требованием переделать работу. Самостоятельно архивировать старые незавершённые записи нельзя.

## Данные

- Единый серверный список теперь включает получателей learning_homework_v2 и их реальные состояния.
- Несколько тем одного урока сохраняются отдельными заданиями; старый агрегированный отчёт этого урока не дублируется. Сопоставление только по sourceLessonId, не по названию.
- Завершение домашней работы не превращается в 100% освоения темы или неподтверждённую награду.
- filteredCounts считает выбранный источник до фильтра состояния и лимита. Общий counts сохранён для навигации и экрана «Сейчас».
- При отказе CRM доступные новые задания остаются, но список и счётчики помечаются как неполные.
- При смене фильтра старые строки и числа не показываются под новым заголовком.
- Записи учеников, проценты, деньги и награды в рамках этой работы не корректировались. Отсутствующие в БД назначения этот адаптер не создаёт.

- Обе production-сборки успешны.
- Playwright: 46 проверок экрана «Задания» и регрессии «Сейчас», desktop + mobile. Все API перехвачены, включая аналитику. Это проверка интерфейса на изолированных данных, не подтверждение всех реальных ученических сценариев.
- Проверены ширины 320, 390, 768, 1440; длинные названия; ошибки/повтор загрузки; неполные данные; переход к каноническому заданию; фильтры/URL/перезагрузка; отсутствие выдуманных процентов и сроков.
